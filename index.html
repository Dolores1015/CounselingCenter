諮商服務項目

諮商不是急著給答案，而是在穩定的關係裡，看見情緒、關係與選擇背後真正的需要。

個別諮商

2000-3000元 / 50分鐘

當你遇到感情、婚姻、親子關係、原生家庭、人際互動、生涯選擇、職場壓力，或焦慮、憂鬱、失眠等困擾時，心理師會陪你梳理經驗，重新整頓生命的方向。

伴侶 / 婚姻諮商

2400-3800元 / 80分鐘

當關係裡出現溝通困難、冷漠、衝突或不安全感，心理師會協助你們理解彼此的需要，練習更清楚地表達，慢慢修復信任與親密。

親子 / 家庭諮商

2400-3800元 / 80分鐘

透過家庭諮商看懂問題背後的互動模式，整理關係中的委屈、期待與無奈，讓家人有機會重新聽見彼此，也讓愛再次流動。

青少年 / 兒童諮商

2000-3000元 / 50分鐘

以孩子能理解的媒材、遊戲與對話進入內在世界，陪伴他們表達情緒、改善適應困難，也協助照顧者找到更合適的支持方式。

頌缽治療

2000-3000元 / 50分鐘

在聲波共鳴與專注當下的練習中，讓緊繃的身心慢慢沉澱。頌缽深厚穩定的頻率，陪你回到更安定、更能休息的狀態。

催眠治療

2500-3500元 / 50分鐘

催眠並非操控，而是在安全、信任的關係中，溫柔地與潛意識連結。陪你在清明的狀態裡，看見內在資源與新的可能。
